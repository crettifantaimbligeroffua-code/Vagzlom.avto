# Vazlom.avto — редагування в одному місці

## Де міняти сайт
Відкрий `config.py` у Thonny.

У цьому файлі зібрані налаштування сайту:
- назва, заголовки, місто, адреса та графік;
- телефони для всіх кнопок «Зателефонувати»;
- меню;
- марки та моделі;
- швидкий підбір Golf / Jetta / Passat / Touran та цілих марок Renault / Ford / Dacia;
- паливо, коробки, кузови та привід;
- усі поля «Додати авто»;
- усі детальні характеристики автомобіля;
- додаткові послуги та їх описи;
- ремонт та ціни;
- усі основні тексти, кнопки та повідомлення;
- ліміт фотографій;
- стандартні дані адміністратора.

## Важливо
Автомобілі, які вже додані на сайт, зберігаються у `vagzlumauto.db`. Їх можна змінювати через «Додати» → «Існуючі авто» → «Редагувати» або видаляти там же.

`config.py` керує налаштуваннями та довідниками, а база — реальними оголошеннями.

Після зміни `config.py` збережи файл і перезапусти `app.py`.


## Оновлення моделей
Список моделей доповнений поколіннями та поширеними модифікаціями. У полі моделі введіть назву (наприклад Golf, Golf VII, Touran 1.6 TDI, Passat B8 або Q5 FY) і виберіть варіант зі списку.

## Render: постійна робота
Безкоштовний Render може присипляти сервіс після періоду бездіяльності. Періодичний ping-бот не є надійним способом гарантувати роботу 24/7. Для стабільної постійної роботи потрібен тариф без засинання або хостинг із постійно активним вебсервісом.

## Автоматична реклама в Telegram і TikTok (необов'язково)

Після додавання нового автомобіля застосунок запускає фонове завдання з затримкою 5 хвилин. Воно створює вертикальне MP4-відео зі збережених фото та характеристик, надсилає фотографії/опис у Telegram і передає відео в TikTok Content Posting API. Це найпростіша інтеграція; фоновий таймер працює в процесі Flask і може не виконатися, якщо Render перезапустить/приспить сервіс до завершення 5 хвилин. Для надійного продакшн-варіанта потрібна зовнішня черга/планувальник.

Налаштуй у Render → Environment такі змінні:

- `SITE_URL` — повна публічна HTTPS-адреса сайту, без `/` в кінці.
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота (зберігати лише в Environment, не в GitHub-коді).
- `TELEGRAM_CHANNEL_ID` — `@назва_каналу` або числовий ID приватного каналу. Додай бота в канал адміністратором із правом публікувати повідомлення.
- `TIKTOK_ACCESS_TOKEN` — дійсний OAuth access token з дозволом `video.publish` для TikTok Developer App.
- `SOCIAL_POST_DELAY_SECONDS` — необов'язково, за замовчуванням `300` (5 хвилин).

Для TikTok потрібно зареєструвати застосунок, додати Content Posting API, отримати схвалення scope `video.publish`, авторизувати TikTok-акаунт і пройти аудит застосунку для публічних постів. У режимі `PULL_FROM_URL` домен має бути перевірений TikTok. Токен може спливати; для постійної роботи потрібне безпечне оновлення OAuth-токенів. Без налаштованих секретів публікація пропускається, сайт продовжує працювати.

Відеофайли зберігаються в `static/uploads`; на Render Free локальні файли можуть зникнути після перезапуску/деплою. Для реальної роботи з оголошеннями використовуйте постійне сховище для фото та відео.


## Умови обслуговування та політика конфіденційності

Додано сторінки Flask:
- `/terms` — умови обслуговування
- `/privacy` — політика конфіденційності

Після завантаження цих змін до GitHub і успішного розгортання на Render перевірте, що обидві адреси відкриваються. Перед поданням заявки TikTok перегляньте тексти й переконайтеся, що вони точно описують фактичні процеси сайту та його обробку даних.


## Збереження оголошень і налаштувань на Render

База даних SQLite, оголошення, шаблон Telegram і завантажені фото зберігаються в папці `DATA_DIR`. Щоб вони не зникали після нового deploy/restart на Render:

1. У Render відкрий Web Service → **Disks** → **Add Disk**.
2. Mount Path встанови `/var/data`.
3. У Environment додай `DATA_DIR` зі значенням `/var/data`.
4. Збережи зміни та дочекайся deploy.

Важливо: зміна коду сама по собі не створює постійний диск. Без диска Render може очистити локальні файли під час перезапуску або нового deploy. Якщо база `vagzlumauto.db` або фото вже є в старому deploy, їх треба окремо перенести на диск, інакше сайт стартує з нової порожньої бази.
