# Vazlom.avto — версія з постійною базою PostgreSQL

Ця версія підтримує `DATABASE_URL`: оголошення, користувачі, налаштування і нові завантажені фотографії зберігаються у PostgreSQL, а не лише у файловій системі Render.

## Обов'язкове налаштування Render

1. Створи PostgreSQL database у Render або в іншого PostgreSQL-провайдера.
2. У Web Service → Environment додай `DATABASE_URL` і встав **Internal Database URL** (для бази Render) або URL від провайдера. Не публікуй це значення.
3. Переконайся, що `SECRET_KEY`, `ADMIN_EMAIL` і `ADMIN_PASSWORD` задані як Environment Variables. Використовуй довгий випадковий `SECRET_KEY` і власний пароль адміністратора.
4. Build command: `pip install -r requirements.txt`
5. Start command: `gunicorn app:app`
6. Після першого запуску перевір сайт, вхід в адмінку, додавання авто і відкриття фото.

Якщо `DATABASE_URL` відсутній, застосунок використовує локальну SQLite-базу для розробки. На Render вона не гарантує збереження після перезапусків.

## Важливо про старі оголошення

Підключення PostgreSQL не може автоматично забрати базу з уже запущеного Render-сервісу, якщо її файл недоступний цьому архіву. Перед перемиканням треба експортувати старі оголошення/фото з поточного сайту, якщо вони ще доступні, і перенести їх у нову базу. Цей архів зберігає нові оголошення й фото після підключення PostgreSQL, але не може гарантувати відновлення вже зниклих даних.
