# VagZlumAuto

Готовий навчальний/стартовий сайт на Python + Flask + SQLite у стилі ваших скріншотів.

## Можливості

- Публічний каталог автомобілів без обов'язкової реєстрації.
- Реєстрація та вхід.
- Ролі: користувач, редактор, адміністратор.
- Адміністратор може видавати/знімати права редактора.
- Редактор та адміністратор можуть додавати авто.
- Фотографії додаються через звичайний вибір файлів з ПК або телефона, не через URL.
- Галерея фото на сторінці автомобіля.
- Фільтр авто за маркою та моделлю.
- Розділи Запчастини, Ремонт, Колеса та диски.
- Темна синьо-чорна тема, червоні акценти та анімовані деталі на фоні.
- SQLite база даних.

## Запуск

1. Встановіть Python 3.10+.
2. Відкрийте термінал у папці проєкту.
3. Виконайте:
   `pip install -r requirements.txt`
4. Запустіть:
   `python app.py`
5. Відкрийте `http://127.0.0.1:5000`.

## Перший адміністратор

За замовчуванням:
- Email: `admin@vagzlumauto.local`
- Пароль: `Admin123!`

Для реального сайту ОБОВ'ЯЗКОВО змініть ці значення через змінні середовища:
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`
- `SECRET_KEY`

Приклад для Windows PowerShell:
`$env:ADMIN_EMAIL="ваш-email"`
`$env:ADMIN_PASSWORD="складний-пароль"`
`$env:SECRET_KEY="довгий-випадковий-ключ"`

## Важливо для реального розгортання

Це готовий стартовий варіант, але перед публікацією в інтернет варто додати CSRF-захист, rate limiting, резервне копіювання БД, перевірку MIME/розміру зображень, HTTPS та окреме сховище для фото.
